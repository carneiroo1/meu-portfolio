# 🗂️ Portfólio — Artur Carneiro

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro. Apresenta minha trajetória como desenvolvedor, tecnologias que utilizo e projetos que construí.

🔗 **[Ver portfólio online](https://artur-carneiro-portfolio.vercel.app)** <!-- substitua pelo link do seu deploy -->

---

## ✨ Funcionalidades

- **Tema escuro/claro** com alternância por botão e preferência salva no `localStorage`
- **Design responsivo** adaptado para mobile, tablet e desktop
- Navegação com **scroll suave** entre seções
- Ícones SVG que se adaptam automaticamente ao tema ativo
- Fontes modernas via Google Fonts (Space Grotesk + Quicksand)

## 🚀 Como rodar localmente

Não precisa de instalação — é HTML puro. Basta clonar e abrir no navegador:

```bash
git clone https://github.com/carneiroo1/portfolio.git
cd portfolio
```

Depois abra o `index.html` diretamente no navegador, ou use uma extensão como o **Live Server** no VS Code para ter recarregamento automático.
